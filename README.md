# Cryptography and Network Security Practicals

A collection of Python implementations of Cryptography and Network Security laboratory practicals. This repository contains programs covering classical encryption techniques, modern cryptographic concepts, hashing algorithms, key exchange mechanisms, digital signatures, and common security attacks.

The objective is to understand how these algorithms work through simple, interactive Python programs that accept user input and display the corresponding output.

## Technologies Used

- **Language:** Python 3
- **IDE:** Google Antigravity Ide
- **Operating System:** Ubuntu Linux
- **Version Control:** Git and GitHub

## How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project directory

```bash
cd Cryptography-and-Network-Security
```

### 3. Run a practical

```bash
python3 03_shiftCipher.py
```

Replace the filename with the practical you want to execute.

## Learning Approach

Each practical is designed to include:

- A simple, beginner-friendly Python implementation.
- Comments explaining the important steps of the algorithm.
- Interactive input for plaintext, keys, and other required parameters.
- Output displaying the encrypted or decrypted result.
- Mathematical concepts and logic behind the algorithm.

## Learning Objectives

- Understand the fundamentals of cryptography and network security.
- Implement classical substitution and transposition ciphers.
- Explore hashing and password protection techniques.
- Understand public-key cryptography and digital signatures.
- Implement key exchange mechanisms.
- Demonstrate common security vulnerabilities in controlled environments.
- Develop practical problem-solving skills using Python.

## Disclaimer

This repository is intended for educational purposes as part of Cryptography and Network Security laboratory coursework. Security attack demonstrations are designed for controlled local environments and should not be used against systems without authorization.
